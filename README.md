# Grammarlix for Windows

Download the **offline x64 Setup EXE** from [Grammarlix Beta 3](https://github.com/FarzadAziziZade/Grammarlix/releases/tag/v2.13.0-beta.3).

Grammarlix provides grammar checks under your control through its floating icon and Review window, plus offline English-to-Farsi translation with the bundled Hy-MT2 translation model. The installer includes CPU/GPU engines and the Microsoft WebView2 offline runtime installer.

Install Beta 3 manually. Its signed automatic update feed will be added when the accompanying update signature is available. The older Beta 2 feed remains available.

This public repository distributes installers, checksums, documentation, and license notices. The application source is maintained privately. License notices for Harper, the translation engine, and the Hy-MT2 model are included in the installer.
